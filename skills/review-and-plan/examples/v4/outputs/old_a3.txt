Probably worth a trial, but not across your private repos on day one. This is a solo judgment from the excerpts you gave me, with no independent review, and I haven't seen the install script or the code that actually captures data.

Why a cautious trial rather than a plain yes:

- It records a lot by default. The README says it automatically captures tool usage observations. The defaults you pasted skip only a handful of low-signal tools (TodoWrite, Skill and similar). CLAUDE_MEM_SKIP_BASH_PATTERNS is empty, so every shell command is captured. CLAUDE_MEM_EXCLUDED_PROJECTS is also empty, so no project is excluded.
- Secret redaction is off by default. CLAUDE_MEM_REDACT_ENABLED and CLAUDE_MEM_REDACT_GENERIC_ENABLED are both 'false'. Tokens or passwords that show up in a command or tool output would be stored as-is. The generic redaction, which covers un-prefixed credentials like password=, *_TOKEN= and Authorization: Bearer, is a second opt-in.
- The provider defaults to 'claude' (CLAUDE_MEM_PROVIDER). The summaries are generated by a model, so I'd expect captured content to be sent to an LLM, but the excerpts don't show where. I also don't know where the stored data lives. For private repos, that is the main thing to confirm.
- Install is a single `npx claude-mem install`. I haven't read what it changes, such as hooks or settings.

What I'd do:

1. Read the install script and the data-storage docs first. What I'd want to know is where the observations are stored and what leaves your machine.
2. Try it on one low-stakes repo, not the private ones.
3. Before any private repo, set CLAUDE_MEM_REDACT_ENABLED and CLAUDE_MEM_REDACT_GENERIC_ENABLED to 'true'. Add the sensitive projects to CLAUDE_MEM_EXCLUDED_PROJECTS and set a CLAUDE_MEM_SKIP_BASH_PATTERNS regex for commands that handle secrets.
4. After a few sessions, check whether the memory is useful. If the recall is not better than what you already get, remove it.

Whether it's worth it depends on one thing I don't know: do you lose useful context between sessions often enough that you'd miss it? If so, trial it. If not, skip it, because the cost is a new always-on recorder in your private work.
