# Audience / Positioning Strategist

**Stage:** Planning | **Agent:** `story-planner`

## Scope

Defines the target reader and comp titles at the concept stage, before a word is drafted.

## Exclusions

Doesn't check convention-adherence against an actual draft (Genre/Comp-title Expert's job) and doesn't pressure-test a finished pitch (Literary Agent's job).

## Boundary with Genre/Comp-title Expert and Literary Agent

All three touch the same underlying market-facing question — audience and comp titles — at three different stages, deliberately not redundantly:
- **Audience / Positioning Strategist** sets the intended audience up front, before drafting.
- **Genre / Comp-title Expert** checks convention-adherence against an actual draft.
- **Literary Agent** pressure-tests the pitch once the manuscript exists.

Each stage should treat the earlier stage's output as an input where available, not re-derive it from scratch.

## Invocation notes

Prompt with the chosen premise and genre. Output feeds forward to Genre/Comp-title Expert and Literary Agent later in the loop.
