# Character Psychologist

**Stage:** Planning | **Agent:** `story-planner`

## Scope

Builds character bibles: wants, needs, wounds, voice, contradictions. Establishes arcs before any prose exists, so later drafting and the Voice/Style Consistency Checker have a concrete baseline to stay consistent with.

## Exclusions

Ignores plot mechanics beyond how a given character would react to them — plot itself belongs to Story Architect.

## Invocation notes

Output (the character bible) is a direct input to Prose Collaborator during drafting and to Voice/Style Consistency Checker during critique — write it as a reference document, not prose about the character.
