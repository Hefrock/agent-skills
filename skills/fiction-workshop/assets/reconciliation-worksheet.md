# Reconciliation Worksheet

Fill this in yourself after a `/critique` (or `/check`) round produces one or more isolated persona notes. This worksheet structures the synthesis — it doesn't do it for you. Reconciling contradictory feedback is deliberately the author's job (see SKILL.md's Reconciliation section); nothing here should be filled in by an LLM persona on your behalf.

## Findings

| Persona | Finding (one line) | Keep / Reject / Defer | Notes |
|---|---|---|---|
| | | | |
| | | | |

- **Keep** — this note is right and should shape the next draft.
- **Reject** — this note is wrong, out of scope, or contradicted by a Keep from another persona; say why in Notes.
- **Defer** — real, but not for this pass (e.g. a Developmental Editor finding that needs a Story Architect replanning pass first, not a direct scene rewrite).

## Consolidated direction

Write the one instruction set that actually goes to `/draft` next. This is the only part `story-drafter` (Prose Collaborator) or `story-doctor` (Scene Doctor) should ever see — never the raw findings table above.
