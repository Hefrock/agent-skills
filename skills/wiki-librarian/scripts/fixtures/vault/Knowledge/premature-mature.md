# Premature Mature

Claims to be mature, but receives only one inbound link and links out to
nothing — total links (1) is under the 2-link minimum a genuinely mature
page needs. Deliberately has zero outbound links so it is NOT also an
orphan (orphan requires zero *inbound*; this page has exactly one).
